# Python Dungeon Crawler

A terminal-based 2D dungeon crawler written in Python. I built this to practice Object-Oriented Programming (OOP) and turn-based game logic while creating an interactive CLI game.

## Features
- **Grid-Based Movement:** Navigate a 5x5 dungeon map rendered right in your terminal using standard WASD controls.
- **Random Combat Encounters:** Every step you take has a 30% chance to trigger a turn-based fight against different monsters (Goblins, Skeletons, Orcs).
- **Player Stats & Loot:** Track your HP and gather gold as you defeat enemies and make your way toward the dungeon exit.

## Concepts Explored
- Object-Oriented Design (`Player` and `Monster` classes)
- Game loops and state management
- 2D matrix rendering with nested loops
- Basic probability using Python's `random` module
